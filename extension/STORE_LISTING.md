## 詳細な説明

```
phishing-url-checker は、ページ内のリンクにカーソルを合わせるだけで
フィッシングサイトの危険度を判定し、警告を表示するブラウザ拡張機能です。

■ 主な機能
・ホバーするだけで危険度を判定(🟢安全 / 🟡注意 / 🔴危険)
・危険と判定したリンクはクリック時に自動でブロックし、警告画面を表示
・「リスクを理解して続行」を選んだ場合のみ本来のリンク先へアクセス可能

■ 何を検出するか
・有名ブランド(Google、Amazon、PayPalなど)へのなりすましドメイン
・ブランド名の綴りを意図的に似せたタイポスクワッティング
  (例: goog1e.com、paypa1-login.com)
・無料ホスティングサービス(firebaseapp.com、herokuapp.comなど)上の
  なりすましサイト

■ プライバシー
すべての判定はブラウザ内で完結しており、外部サーバーへの通信は
一切行いません。閲覧履歴やアクセスしたURLが送信されることはありません。
詳細はプライバシーポリシーをご確認ください。

■ こんな方におすすめ
・不審なメールやチャットのリンクをクリックする前に確認したい方
・組織内でフィッシング対策リテラシーを高めたい方
```

## スクリーンショット撮影ガイド

Edge Add-onsは通常1280×800(または640×400)のスクリーンショットを複数枚
要求します。以下の3枚を撮影すれば十分な訴求力になります。

1. **ホバーバッジ**
   - `npm run serve:test-page` でテストページを開く
   - 「2. ブランドなりすまし」か「5. 複合パターン」のリンクにマウスを乗せ、
     🔴危険バッジが表示された状態でスクリーンショット
2. **警告モーダル(ブロック画面)**
   - 同じリンクをクリックし、赤い警告モーダルが表示された状態で撮影
   - URLと理由がはっきり読める画面サイズにしておく
3. **拡張機能アイコン(ツールバー)**
   - `edge://extensions` ではなく、通常のブラウジング画面でツールバー上に
     信号機アイコンが表示されている状態を撮影(拡張機能一覧のピン留め推奨)

撮影後、ファイルは`extension/store-assets/`などにまとめておくと提出時に
迷いません(このフォルダはGit管理対象外にしておくことを推奨します)。
